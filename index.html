Mặc định hệ thống tự đọc file từ thư mục images/header.png, images/footer.png, images/thu2.png ... images/chuanhat.png. Bạn có thể thay thế bằng file khác ở đây nếu muốn!

2. Ảnh Footer (`footer.png`) Đọc từ `images/footer.png` hoặc `footer.png`
3. Ảnh Huy Hiệu Ngày Lễ (`thu2.png` -> `chuanhat.png`)
